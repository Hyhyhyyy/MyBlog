TOOLBOX / 实用工具箱

随手可用的小工具

TOOL 01

Markdown → PDF

左侧写 Markdown，右侧实时预览；一键调用浏览器「另存为 PDF」。支持标题、加粗、列表、表格、代码块、Mermaid 图、引用、链接、图片（表格/图片/Mermaid 均会原样进入 PDF）。
