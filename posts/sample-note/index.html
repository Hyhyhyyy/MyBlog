    样例笔记 · Markdown 写作演示

    这是一篇用 blog/md_post.py 发布的样例笔记，用来演示整个 Markdown → 博客文章页 的最短流程——在 IDE 里写 .md，运行脚本，推上 GitHub Pages。

    这篇笔记能展示什么

    • 演示 加粗、斜体 与 行内代码；
    • 展示无序 / 有序列表与引用块；
    • 给出一段代码块（这里用 bash 起头的围栏，渲染后原样展示）；
    • 给出一条外部链接；
    • 配一张方形 PNG 封面，在文章页与学习页以方形圆角展示。

    最短发布流程

    1. 在 IDE 里写一份 .md（带或不带 frontmatter 都行）；
    2. 运行 python blog/md_post.py <文件>.md --cover 封面.png；
    3. 运行 python blog/sync.py 推到 GitHub Pages。
    封面图片建议 1:1 方形 PNG，会被复制为 posts/<slug>/cover.png 并在文章页与学习页以方形圆角展示；不传 --cover 则生成占位渐变 SVG。

    外部链接示例：回到博客首页。

    # 一行命令发布
python blog/md_post.py notes/my-note.md --cover notes/cover.png --force && python blog/sync.py
    想再改一遍文章？改完 .md 重新跑 md_post.py ... --force，再 sync.py 即可。

    以上就是全部。
