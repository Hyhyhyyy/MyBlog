📝 怎么选（实用建议）

偏方法 / 训练创新（VLM 架构、微调策略）→ NeurIPS / ICML / ICLR / ACL

偏视觉 / 医学落地（WSI 诊断、视觉编码）→ CVPR / ICCV / MICCAI / MIDL

偏代码审查工具 / 实证（DSH Reviewer Bot 评测、Agent 效果）→ ICSE / FSE / ASE / TSE

偏训练系统 / 加速器 / 分布式（LLaMA-Factory、A100 训练、调度）→ MLSys / OSDI / ATC / SC / ASPLOS / ISCA

先读后投：在最新 proceedings 里搜 vision-language model / code review / LLM agent SE / ML systems，确认对口 track 与审稿口味再定目标 venue。
